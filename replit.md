# Photo Gallery

This project is a React and TypeScript photo gallery built with Vite and Tailwind CSS.

## Run on Replit

- Start the app with the **Start application** workflow.
- The workflow runs `npm run dev` and serves the app on port 5000.
- No environment variables are currently required.

## Useful commands

- `npm run lint` checks TypeScript types.
- `npm run build` creates a production build in `dist/`.
